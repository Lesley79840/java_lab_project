# java lab project

## Project Overview

This repository contains a Java application developed as part of a programming lab assignment.

The project is used to practise Java development, version control with Git, and collaboration through GitHub.

## Project Structure

`src/` — Contains the Java application source code.
`pom.xml` — Maven configuration and dependencies.
`mvnw` — Maven wrapper for macOS and Linux.
`mvnw.cmd` — Maven wrapper for Windows.
`README.md` — Project documentation.

## Running the Project

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Wait for Maven dependencies to load.
4. Locate the application's main Java class.
5. Run the application from IntelliJ.

## GitHub Collaboration

This project supports collaborative development using Git branches, commits, and Pull Requests.

Contributors can suggest improvements by creating a separate branch and submitting a Pull Request for review.
